[F] Deployment Settings Files deployment-settings/{env}/deployment-settings.json
Purpose: maps logical Connection References and Environment Variables to env-specific values.
Token replacement: values wrapped in #{VarName}# are replaced at deploy time from GitHub repository variables or environment secrets of the same name.
Example: "ConnectionId": "#{Dev_DataverseConnId}#" → substituted with GitHub variable Dev_DataverseConnId.
